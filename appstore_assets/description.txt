REVIEW NOTES (for Apple reviewer):
This app provides biometric liveness verification for visa application portals.
The app uses a session-based system: users receive a 4-digit code from the BLS
visa portal, enter it in the app, complete a liveness check, and the result is
sent back to the portal. Camera access is required for the liveness detection
process only.

Test account: Not required (session codes are generated externally)
Demo code for review: The reviewer can use code: 0000 (test mode)
